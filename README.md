# Creature-Power-Creep-in-MtG
An exploratory analysis attempting to quantify creature power creep in the trading card game *Magic: The Gathering*.

This was a final project for a graduate-level machine learning course. Feedback is appreciated, as are any ideas to expand the project.

## Local Setup
```
git clone https://github.com/AgentSamSA/Creature-Power-Creep-in-MtG.git
cd your-repo
pip install -e .
```
Install dev dependencies with
```pip install -e [".dev"]```

You can run ```jupyter notebook``` to run the notebook, located in the ```notebooks``` folder.

Alternative, you can open this notebook in Google Colab. <a target="_blank" href="https://colab.research.google.com/github/AgentSamSA/Creature-Power-Creep-in-MtG/blob/main/IMT574_FinalProject.ipynb">
